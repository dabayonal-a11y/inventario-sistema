Bienvenido al Sistema

Esta aplicación web permite registrar, consultar, actualizar y controlar los productos de una empresa de forma eficiente, integrando tecnologías modernas de Frontend y Backend.

El sistema conecta una interfaz intuitiva desarrollada en HTML5, CSS3, Bootstrap 5 y JavaScript con un potente servidor backend en Java Spring Boot y Spring Data JPA, respaldado por una base de datos relacional MySQL.

Consultar Inventario Registrar Producto

Funciones del Sistema

  • Registrar productos en la base de datos MySQL
  • Consultar y filtrar el inventario en tiempo real
  • Actualizar existencias, precios y proveedores
  • Eliminar productos con confirmación de seguridad
  • Cálculo automático de subtotales y total del inventario

Proceso de Uso

  1. Ingresar al sistema y revisar el resumen del inventario
  2. Ir a "Registrar producto" y llenar el formulario con validaciones
  3. Guardar el producto para enviarlo a Spring Boot y MySQL
  4. Ver el producto reflejado inmediatamente en la tabla de inventario
  5. Editar existencias o eliminar artículos cuando sea necesario
